# Languages

English · [中文](zh-CN/i18n.md)

Command names, flags, code, API names and JSON keys are English. Everything shown to a
person follows the selected language:

* CLI messages and `--help` texts, report headings, capability explanations, finding
  descriptions and notices come from message catalogs in
  `src/extrospect/i18n/locales/<code>.json` (shipped: `en`, `zh-CN`; `zh-TW` falls back to
  `zh-CN`, every other language to English);
* text written by an LLM (triage behaviour, evidence claims, attack chain, summary) is
  requested in the selected language - any language the model knows, e.g. `ja`, `ko`, `fr`;
* extension names are resolved from the extension's own `_locales` in the user's language;
* code, quotes, URLs and domains are never translated.

Selection order: `--lang` > `EXTROSPECT_LANG` > `language` in `config.toml` > the OS
locale (`LC_ALL`, `LC_MESSAGES`, `LANG`, `LANGUAGE`, Windows UI language) > English.
`extrospect languages` lists the options.

## Adding a language

1. Copy `en.json` to `<code>.json` (e.g. `ja.json`) and translate the values. Keep the
   keys and the `{placeholders}` unchanged.
2. Add the language to `LANGUAGE_NAMES` in `src/extrospect/i18n/__init__.py` if missing.
3. Run `uv run pytest tests/test_i18n.py` - it checks that every catalog has exactly the
   English keys with the same placeholders, and that every key used in the code exists.

Prompt-injection detection patterns live in `src/extrospect/llm/sanitize.py`; add
patterns for the new language there as well.
