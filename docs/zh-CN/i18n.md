# 多语言

[English](../i18n.md) · 中文

命令名、参数、代码、API 名和 JSON 字段都是英文。所有给人看的内容都跟随所选语言：

* CLI 提示和 `--help` 文字、报告标题、能力解释、发现的描述和提示信息，来自
  `src/extrospect/i18n/locales/<code>.json` 里的消息目录（内置 `en`、`zh-CN`；`zh-TW` 回退到 `zh-CN`，
  其他语言回退到英文）；
* LLM 写的内容（分诊的行为描述、证据说明、攻击链、摘要）会要求用所选语言输出——模型会的任何语言都可以，
  例如 `ja`、`ko`、`fr`；
* 扩展名称会按用户的语言，从扩展自带的 `_locales` 里解析；
* 代码、引用、URL 和域名永远不翻译。

选择顺序：`--lang` > `EXTROSPECT_LANG` > `config.toml` 里的 `language` > 系统区域设置（`LC_ALL`、
`LC_MESSAGES`、`LANG`、`LANGUAGE`、Windows 界面语言）> 英文。`extrospect languages` 会列出可选项。

## 添加一种语言

1. 把 `en.json` 复制为 `<code>.json`（例如 `ja.json`），翻译其中的值。键名和 `{占位符}` 保持不变。
2. 如果 `src/extrospect/i18n/__init__.py` 的 `LANGUAGE_NAMES` 里还没有这种语言，加上去。
3. 运行 `uv run pytest tests/test_i18n.py`：它会检查每个目录的键是否和英文完全一致、占位符是否相同，
   以及代码里用到的每个键都存在。

提示注入的检测规则在 `src/extrospect/llm/sanitize.py` 里，也要为新语言加上对应的规则。
